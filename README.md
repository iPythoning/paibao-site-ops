# paibao-site-ops

**AI agent 一句话从 0 建站、配置、运营 EmDash 独立站**（外贸 B2B GEO/AI 搜索获客）。

```bash
paibao-site-ops create --domain example.com --brand "Acme Trading"   # dry-run
paibao-site-ops create --domain example.com --brand "Acme Trading" --apply  # 建站
paibao-site-ops deploy --site client-sites/acme --apply              # 部署
paibao-site-ops operate --site client-sites/acme                     # 运营接管(MCP)
```

开源核心（MIT）；Cloud 托管版 + FDE 深度定制付费 → paibaowork.com
