## Docker 真实 secret 契约

模板当前校验强制：

- TURNSTILE_SITE_KEY、TURNSTILE_SECRET_KEY、INQUIRY_FROM_EMAIL。
- ZEPTOMAIL_API_KEY 或 RESEND_API_KEY 至少其一。
- CONTROL_PLANE_URL：精确 HTTPS origin。
- CONTROL_PLANE_SITE_TOKEN：匹配模板格式的站点 token。
- INQUIRY_FROM_NAME 可选；SEO_CANONICAL_* 与受保护站点身份一致。
- secrets 目录 0700，site.env 常规文件 0600，禁止符号链接。

这主要是存在性/格式/身份校验，不代表 provider 凭据已在线验证或询盘实际到信。禁止塞假值绕门禁；是否让控制面成为可选项属另一个架构决策，不能偷偷改。
